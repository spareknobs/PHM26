# PHM26

This repository contains a collection of SuperCollider scripts developed for the Physical Models course (2025–2026), Institute of Sonology, Royal Conservatoire in The Hague. The examples demonstrate a range of basic physical modelling techniques and sound synthesis approaches.

Requirements

To run the examples, you will need to install the DynGen extension for SuperCollider. 
Installation instructions and documentation can be found here: https://github.com/capital-G/DynGen
Many thanks to Dennis Scheiba for providing this amazing library!

Contents

The scripts are intended as educational examples and provide a starting point for exploring physical modelling synthesis within SuperCollider.
